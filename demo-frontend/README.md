# 循证医学健康问答 · Agent 编排与原文核对工作台 (demo-frontend)

独立 Vue 3 + TypeScript + Vite 前端，围绕**成人高血压与 2 型糖尿病健康知识问答**及 **AI Agent 编排/逐事实引用审核展示**构建，同时在次级入口完整保留科研样本模拟登记（浏览器 `localStorage` 与服务端 SQL `registration_graph_v1`）。

参考项目 `../medix-agent-swarm/` 与 `../MediX-R1/`、后端业务代码及数据库保持不变。

## 启动与构建

```powershell
cd 'E:\medical agent\demo-frontend'
npm run dev
```

浏览器打开 `http://127.0.0.1:5178/`（固定 5178 端口，通过 `/api` 同源代理连接本地 `http://127.0.0.1:8010` 后端）。

类型检查、离线回归测试与生产构建：

```powershell
npm run test
npm run build
```

## 当前试用范围与题目

默认使用本地模拟，不调用 DeepSeek、Mem0 或实时向量检索。自由输入采用少量关键词分支和固定快照回答，不能用于衡量真实模型的医学质量；模拟会话暂存在页面内存中，刷新后重置。样本演示记录单独保存在浏览器 localStorage。

| 入口 | 问题/场景 | 重点观察 |
| --- | --- | --- |
| 新建会话直接输入 | 血压 120/80 中两个数字分别表示什么？测量血压前 30 分钟需要注意什么？ | 单任务、两段正文及逐事实原文 |
| 同会话继续输入 | eGFR 与 UACR 有什么区别，可以互相替代吗？ | 多轮界面、多个来源；模拟回答不代表真实上下文推理 |
| 左侧 UACR 预设 | 医生让我查尿白蛋白肌酐比，这个指标比较什么？ | 单任务完整回答，一条事实绑定多段原文 |
| 左侧 HbA1c 预设 | HbA1c 与指尖血糖有什么区别，检查需要空腹吗？ | 模拟 3 任务依赖、省略 2 条原句及审核说明 |
| 左侧降压药预设 | 降压药机制与具体剂量询问 | 审核拦截、错误解释，不展示被拦截初稿 |
| 左侧急症预设 | 疑似酮症酸中毒急症风险信号 | 安全规则出口、0 个任务，不代表任意自由输入均实现急症识别 |
| 左侧服务不可用预设 | 血压 120/80 含义与测前准备，然后点击重试 | 模拟失败→模拟成功，不触发真实 Provider |
| 新建会话直接输入 | 请介绍花粉过敏的检查方法。 | 固定库外/无来源提示，不应编造引用 |

多 Agent、审核失败和急症流程请从左侧预设进入。直接输入 HbA1c 或 UACR 等词并不保证命中对应预设，当前没有通用的模拟意图识别器。

顶部“模拟登记”可体验：示例/规则提取草稿、修改字段升版、核对、明确确认、查看合成编号、取消及缺字段校验。此处仅使用 DEMO 合成数据。

“后端联调”另有 JWT 登录/注册、本人 SQL 会话、运行状态与记忆维护入口，需要后端及相应 Provider 就绪；上述模拟验证不代表这些真实接口已经联调通过。

## 核心特性与信息架构

页面采用 **“会话列表（左）— 提问与回答阅读中心（中）— 可折叠引用原文与执行审核栏（右/窄屏抽屉）”** 结构：

1. **证据一致性与模拟/真实严格隔离**
   - **本地模拟演示（结构模拟）**：所有模拟运行、请求、检查点和会话均使用 `sim-` 前缀，绝不复用真实运行 UUID，也不宣称“真实复现/回放”。
   - **已校验只读 NLM 快照 Fixture (`src/verifiedNlmFixture.ts`)**：引用原文取自已校验的公开 NLM/MedlinePlus 资料快照，`source_sha256`、`version`、中文摘述字符区间与英文原文 `quote` 字符偏移 `[start..end]` 完全一致，并由 `src/workflow.test.ts` 自动回归校验。
   - **后端联调（8010 真实接口）**：连接本地 8010 服务，接口失败时明确展示原因与重试入口，**绝不静默切换为本地模拟答案**。
   - **诚实审核标识**：明确区分 `模拟引用核对完成` / `模型引用核对完成` 与 `医学专业审核：未执行`。

2. **宽敞阅读中心与逐事实引用定位**
   - 右侧证据栏默认收起，新会话无运行记录时自动隐藏空面板，优先保障正文阅读空间。
   - 正文采用 `16px` 易读排版，按 `claim_reviews` 与 `final_start`/`final_end` 提供逐句 `[引 N]` 入口；点击句子或引用标记即展开右侧面板，置顶显示该句的核对状态与全部支撑英文段落（支持一事实多段落），并高亮对应来源卡片。
   - 当运行仅提供整轮来源而无逐句映射时，如实显示“暂无逐事实映射”，不按段落顺序猜测绑定；SHA256、字符区间与分值收纳于可展开技术信息中。

3. **省略记录直达与动态任务依赖图**
   - 点击回答中的“查看被省略的 N 条原句 →”，直接打开右侧面板并默认筛选“未进入最终回答”的省略项，展示省略原句、原因、审核轮次与参考原文，并提供一键返回全部审核记录。
   - 执行详情提供按真实任务与 `depends_on` 生成的波次依赖图（单任务显示单任务，多任务按实际依赖连接，0 任务显示规则直出），底层节点事件流与错误码默认折叠。

4. **次级入口：科研样本模拟登记**
   - 点击顶部“模拟登记”打开次级抽屉，完整保留浏览器 `localStorage` 模拟登记与服务端 SQL `registration_graph_v1` 模拟登记链路。

## 文件说明

- `src/App.vue`：主工作台布局、双模式状态隔离、分组会话导航、键盘 `Escape` 关闭与焦点恢复。
- `src/ConversationTurnCard.vue`：单轮对话阅读卡片、逐事实 `[引]` 交互入口、省略项直达入口、简明失败说明卡片。
- `src/EvidenceAndTracePanel.vue`：可折叠右侧/抽屉面板，含逐事实原文定位器、可展开技术元数据、省略项优先筛选与动态任务依赖图。
- `src/verifiedNlmFixture.ts`：只读 NLM 公开资料快照 Fixture 与偏移/哈希一致性校验器。
- `src/mockMedicalScenarios.ts`：5 个本地结构模拟场景与追问生成逻辑。
- `src/types.ts` / `src/medicalLabels.ts`：与后端 `app/schemas.py` 对齐的类型契约、逐事实映射解析与波次构建工具。
- `src/SimulatedRegistrationDrawer.vue` / `src/RegistrationPanel.vue` / `src/workflow.ts`：次级模拟样本登记组件与状态机。
- `src/workflow.test.ts`：16 项离线回归测试（含登记状态机、NLM 快照、引用偏移及正文保留）。
- `qa/browser-regression.mjs`：Codex CUA 浏览器回归，14 项抽屉检查与 5 项实际正文渲染检查；执行方式见 `QA.md`。
