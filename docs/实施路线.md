## 2. 免费版预算与配置

2026-10-13 核对 [Mem0 官方定价](https://mem0.ai/pricing)：Hobby 每月免费 10,000 次 add requests、1,000 次 retrieval requests，1 个项目，终端用户数量不限。实际可用额度以用户控制台为准，本次未查询账户。

按每轮一次长期记忆检索估算，可支持约 1,000 轮/月，折算 30 天约 33 轮/天；这是预算估算，不是余额保证。个人学习和小规模演示通常可以先用免费版，频繁真实回归会更快耗尽检索额度。

控制办法：本轮统一检索一次，结果供各 Worker 复用；追加查询与重试单独计数；普通回归用 fake Mem0；只写有长期价值的信息。额度不足显式降级，不自动升级套餐。

DeepSeek 官方当前模型名为 deepseek-flash，初期显式关闭思考模式，Mem0套餐与模型费用分别统计。[DeepSeek 接入说明](https://api-docs.deepseek.com/)、[模型与计费](https://api-docs.deepseek.com/quick_start/pricing/)

用户只填写 backend/.env 中的两项 API Key，保留其他值；不要把密钥发到聊天。未来应用会以明确路径读取配置，不输出密钥或完整配置。JWT签名密钥与API Key分别生成和使用。填写密钥不代表自动开始云端调用。

每批回报：改了什么、怎么启动、哪些离线检查通过、哪些真实观察完成、剩余缺口。对可复现缺陷先写失败测试再修复；not_run和skipped单列，不沿用手册指标。

真实接入使用公开/合成测试内容，显式启用指定provider，开始前说明次数、数据范围和预算；先单步冒烟，再完整单轮，最后小规模多任务。不自动充值或升级；结果不明先核对，不机械重试写入。真实测试与普通离线回归分开。

应用运行时可读取用户填写的密钥，配置检查只输出字段是否齐备/验证是否通过，不打印值。后续编辑不得覆盖已有.env或用户密钥；使用日志和异常脱敏。
