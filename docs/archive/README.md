# 历史模块与实验套件归档库 (Archive)

本目录用于存放系统重构与升级过程中解耦剥离的独立实验套件与历史原型备份，保持主干代码库的极简与高效。

## 📦 归档内容清单

### 1. `MediX-R1_backup.zip` (大小: ~530 KB)
- **归档时间**：2026-10-27
- **模块定位**：基于强化学习（RL）的医疗推理模型微调与评测套件。
- **核心组件**：
  - `training/`：基于 `verl` 强化学习训练框架的 R1 训练脚本（DAPO、GSPO 算法）及模型合并工具；
  - `eval/` 与 `eval2/`：`MedEvalKit` 评测基准套件与评测配置（tasks.yaml、eval.sh 等）。
- **如何还原**：
  若后续需要对底层大模型（如 Qwen2.5-VL / Qwen3-VL）进行强化学习微调或本地基准打分，可直接在项目根目录下解压该 zip 文件：
  ```bash
  # 在根目录下解压恢复
  unzip docs/archive/MediX-R1_backup.zip -d .
  ```
