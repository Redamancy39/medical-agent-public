## 原因与修复

1. **作者和Reviewer看到的证据不一致。** 检索短引句没有展示居家测量时点的章节引言，Worker据此声称资料缺失；Reviewer读取更完整的英文原文后拒绝这个范围声明。新增 `evidence_context.py`：对正式注册来源先检查SHA256、编辑版本、中文片段和原文锚点，再有限补充原文段落及章节引言；Lead汇总也接收英文上下文。原始文件、向量和检索分数不变；发送模型时去掉已被完整段落包含的重复短引句。
2. **拆分/修复后总字数增长。** 汇总阶段满足180字不意味着恢复独立主语、拆事实、补条件后仍满足。原实现还漏掉了“先修复部分支持内容，再变长”的路径。现在显式字数问题把证据修复和表达合并放入同一次有界改写，结构验证检查总字符数和所有旧已支持事实索引覆盖；独立Reviewer进一步核对语义、限定、单位和否定是否保留。
3. **压缩不能破坏已通过事实。** 候选的 `preserved_facts` 与 `repair_targets` 同时进入独立复审和溯源。候选必须全通过才能替换原已审核主体；长度、格式、预算或复审失败时保留原已支持正文，不截断。未被可靠修复的旧断言继续计入省略。改写最多一次，格式纠正仍受原全局预算限制，不形成无限循环。
4. **真实观察暴露用途误判。** Reviewer将“不用于诊断1型及妊娠糖尿病”扩大成所有用途后误拒。补充通用用途限定规则：不同段落可共同支持两种病的诊断用途限制，该句没有声称不能监测。独立4条合成正反例真实校准全部匹配，范围外监测禁用和绝对不可替代断言仍被拒绝；仅证明这4条案例，泛化未建立。
5. **失败状态可查。** 新增API长度字段和 `review_rewrite_mode/error_code`；超长诊断记录实际与目标字符数，不保存任意原始provider载荷。证据不足与超长分别保留真实状态；空替换是合法结果，不会为了凑一条而制造错误范围声明。
