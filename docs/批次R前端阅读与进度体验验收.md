实施开始于2026-10-15，2026-10-16完成。本批仅修改 `demo-frontend` 及本说明；后端源码、医学知识库、参考项目、用户密钥和冻结题集不动，未新增真实模型或Mem0调用。

## 调整结果

1. **阅读：已验证。** “核心结论”“机制与适用范围”等段落标题从12.5px调整为16px/700字重，正文仍16px。句末引用改成蓝色、无底色的小上标 `[1]` / `[1,4]`，去掉逐句的蓝色底块和“几处原文”徽标；原文数量保留在鼠标提示及定位面板。文末资料链接也使用蓝色。引用的可访问名称、键盘焦点和精确绑定保持可用；手机引用点击区域实测至少24×24px。
2. **原文定位：已验证。** 点击上标仍展开对应英文原文；UACR第2句的3段原文均可定位。展开或切换面板不改变正文；错位、缺失映射及固定声明边界5种实际组件回归通过。模拟资料和医学文案本批未改，不将结构校验当作医学质量认证。
3. **回答说明：已验证。** 原“执行与审核”改为“回答说明”，默认显示结果、实际任务数、引用片段数和核对状态；“逐句核对与未采用内容”“专家分工与处理流程”“开发者诊断”默认折叠。节点事件、HTTP/Token、运行ID和上下文摘要留在开发者诊断中，用户可按需展开。收到新回答不再自动打开右栏。
4. **未采用内容：已验证。** 原橙色“保守省略说明”改成轻量文字与“为什么未采用？”入口。它表示原稿句子未通过原文或使用规则核对，未进入最终回答；可能是证据不足，也可能是模型误判，不等于该句必然错误。点击后直接展开该组并筛选未采用项，保留原句、模型给出的原因和参考原文；没有把未采用句子放回正文。手机抽屉焦点进入、Escape返回该入口均通过。
5. **等待：离线接口回归通过。** 本轮回答内部展示一处流程指示：理解问题 → 查询与作答 → 核对引用 → 保存结果。横条为不定量活动指示，没有百分比或预计剩余时间。现有后端 `stage` 是节点执行后的检查点，因此界面明确说“后端最近记录”；Reviewer运行元数据可明确展示“正在逐句核对”，不依时钟猜下一阶段。尚未收到本次request_id的运行记录时只显示等待，不借用旧轮次状态。进度断联时保留最后已知状态、暂停活动指示并说明尚未确认新进度。

等待轮询从450ms一轮的全量刷新改成1秒一轮、同一时刻最多一组请求，只读取最新运行和事件；调用记录与记忆维护在完整刷新时读取。本次浏览器断言确认等待期间没有重复刷新维护接口或Provider记录。切到新运行时清空上一轮事件、调用与事实选择，避免详情混用。

## 使用

本地预览仍为 `http://127.0.0.1:5178/`。点正文蓝色上标查看原文，点“本轮回答说明”查看概况，点“为什么未采用？”查看原稿与原因。真实后端联调继续使用原账号和SQL历史；开发期间Vue热更新可能重新挂载页面，JWT仅在页面内存中，若已退出登录则用原账号重新登录，无需重新注册。

本批未新增真实云问答验收，进度机制以现有真实接口契约和离线浏览器回归验证；真实答案内容质量沿用独立的后端验收结论。
