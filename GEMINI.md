## Language Preferences

1. Always respond to the user in Simplified Chinese (简体中文), unless explicitly requested otherwise.
2. Use Simplified Chinese for explanations, plans, progress updates, code reviews, and final summaries.
3. Keep source code, variable names, API names, file paths, commands, and technical identifiers in their original language.
4. Preserve English terminology when necessary and provide Chinese explanations.
5. Do not unexpectedly switch to English in the middle or at the end of a response.
6. Write code comments in Chinese unless the project already follows an English-only convention.
